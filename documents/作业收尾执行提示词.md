## 6. 故障处理（Air + MPS 常见问题）

| 症状 | 处理 |
| --- | --- |
| 训练被 `--max-minutes` 截断退出 | **正常行为**。重跑同一条命令即自动 `--resume` 续跑 |
| MPS 崩溃 / 进程被 kill | 同上，重跑续跑；checkpoint 每 epoch 落盘，最多丢 1 个 epoch |
| `RuntimeError: 算子不支持` | 加环境变量 `PYTORCH_ENABLE_MPS_FALLBACK=1` 重跑 |
| 机器发热降频、epoch 变慢 | 正常（无风扇）。暂停 20 分钟再继续 |
| 想中止长任务 | `pkill -f run_all.py` 或 `kill <pid>`；**不要删 checkpoint**，否则前功尽弃 |
| 想看进度 | 打开 :8800 门户的 `#/hw1` / `#/hw2`，或 `tail -f outputs/logs/_run_main.log` |
| 磁盘紧张 | 删旧 `.conda` 目录（`hw1_unet/.conda`、`hw2_sam/.conda`，已废弃）；checkpoints 每个 347MB × 30 个 ≈ 10GB，跑完后可只保留 `*_best.pth` |
