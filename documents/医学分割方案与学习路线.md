# 医学图像分割 + SAM：方案与学习路线

> **作业 1**：医学图像分割，三个 U-Net 系模型横向对比
> **作业 2**：SAM 提示分割（Segment Anything），零样本 → 微调 → 对照
> **前提**：两个方向都没做过；环境为单台 MacBook Air M5（24 GB 统一内存，无 CUDA，无风扇）
> **截止**：2026-11-30（剩余约 6 周）　**本文只做方案与学习路径，不含实现**

---

## 0. 为什么这条线是自洽的

你这次的选择其实比原方案更"顺"，因为它构成一条**单线递进**，而不是两个拼在一起的题目：

```
作业1：全监督小模型（U-Net 系，~30M 参数，无需提示，端到端出掩膜）
          ↓ 在报告里暴露它的三个具体缺陷（边界糊、小目标丢、换数据集就崩）
作业2：提示驱动大模型（SAM ViT-B，91M，需要 box/点提示，零样本可用）
          ↓ 用同一测试集、同一指标做"自动 vs 交互"的范式对比
```

**关键叙事**：作业 1 不是作业 2 的"垫脚石"，而是它的**对照组**。如果没有作业 1，作业 2 就只是"调了个 SAM"；有了作业 1，作业 2 才是"我证明了在什么条件下该用哪一种范式"。这句话就是两份报告的共同主线，也是老师想要的"自己的观点"。

**Transformer 落点（作业 2 硬要求）**：SAM 的 image encoder 是 **ViT-B**（12 层 Transformer，patch 16，输入固定 1024×1024），prompt encoder 与 mask decoder 之间是**双向交叉注意力**。Transformer 在这里不是装饰，而是"图像与提示如何交互"的唯一机制——去掉它，SAM 就不存在。

## 1. 数据决策

### 1.1 候选数据集对比

| 数据集 | 模态 | 规模 | 掩膜 | 获取难度 | 适合度 |
| --- | --- | --- | --- | --- | --- |
| **ISIC 2018 Task 1** | 皮肤镜 RGB | 2,594 训练 + 100 验证 + 1,000 测试 | 有 | **直接下载，无需注册** | ★★★★★ 首选 |
| Kvasir-SEG | 内窥镜 RGB | 1,000 张 | 有 | 直接下载 | ★★★★ 备选（更简单，病灶边界更清晰） |
| BUSI | 乳腺超声 | 780 张 | 有 | 直接下载 | ★★★ 数据偏小 |
| LUNA16 | 肺 CT（3D） | 888 例 / 1,186 结节 | 有 | **需注册申请** | ★★ 3D 切片处理复杂，不建议 6 周内做 |
| ACDC | 心脏 MRI | 100 例 | 有 | 需注册 | ★★ 同上 |

**选定 ISIC 2018**，三条理由：
1. **2D RGB，掩膜干净**，不用处理 CT 的窗宽窗位与 3D 切片堆叠——这一项能省下至少 4 天；
2. 它是皮肤病变分割的**事实基准**，U-Net 系与 SAM 系都有大量已发表结果，你的指标有参照系，报告里能说"我们复现到 XX，接近文献 YY"；
3. 规模（2,594 张）正好落在"能训练出效果、又不至于跑不完"的区间。

> **需要你实测确认的两件事**（W1 第一天做）：病灶前景像素占比的分布（决定损失函数与采样策略）、掩膜是否存在多连通域（决定后处理是否要保留最大连通域）。

### 1.2 数据划分与不平衡处置

- **划分**：优先用官方 split（2,594 / 100 / 1,000）。若要做统计显著性，另做 5 折交叉验证**只用于最终对比**（太贵，只跑最佳两组超参）。
- **不平衡**：皮肤病变前景占比通常在 10%–30% 量级（**待实测**），不像肺结节那样极端，但边界像素极少。处置：**Dice + BCE 混合损失**（Dice 管区域重叠，BCE 管像素级稳定），不做重采样。
- **增强**：随机翻转、旋转 ±30°、缩放 0.8–1.2、色彩抖动（皮肤镜对色偏敏感，这一项别省）、弹性变形（可选）。**验证集只做 resize + 归一化**。

## 2. 作业 1：三个 U-Net 系模型对比

### 2.1 为什么是这三个（不是随手挑的）

| 模型 | 改进轴 | 参数量（估） | 要暴露的短板 |
| --- | --- | --- | --- |
| **U-Net**（Ronneberger, MICCAI 2015） | 基线：编解码 + 跳跃连接 | ~31 M | 小目标漏检、边界平滑过度 |
| **ResUNet**（Zhang, 2018） | + 残差连接：缓解深层退化、加速收敛 | ~30 M | 参数量没涨但收益有限 → 说明"加深不是万能" |
| **Attention U-Net**（Oktay, MIDL 2018） | + 注意力门控：抑制无关区域响应 | ~34 M | 注意力图好看但指标提升有限 → 说明"可解释≠更准" |

这三者恰好覆盖**"结构加深 / 跳跃连接改造 / 特征重加权"**三条主流改进路线，对比有逻辑，不是三个随便的模型。报告里那张"三模型结构图"也好画——差异只在跳跃连接与上采样路径上。

### 2.2 训练配置（先按这个跑，别一开始就调）

| 项 | 设置 | 说明 |
| --- | --- | --- |
| 输入分辨率 | 256×256 | 512 更准但本机慢 4 倍，先用 256 定基线 |
| batch size | 8 | M5 24 GB 足够，配合 fp16 autocast |
| 优化器 / 学习率 | AdamW, 1e-3, cosine 退火 | U-Net 从零训练用 1e-3，别用 1e-4 |
| 损失 | 0.5×BCE + 0.5×Dice | 消融时单独对比 BCE / Dice / 混合 |
| epoch | 30，早停 patience=8 | 2594 张，30 epoch 足够收敛 |
| 随机种子 | 固定 42；关键对比跑 3 个种子报均值±标准差 | 这是"实验严谨"的加分项 |

**耗时估算**（M5 fp16，非实测）：U-Net 256² 单步约 0.3 s，324 步/epoch → **约 1.5–2 分钟/epoch**，30 epoch 约 **1 小时/模型**。三个模型 + 消融，总训练量 **5–8 小时**，分两个晚上跑完。这是这条线相对文本方案的最大优势：**作业 1 的算力压力几乎为零**。

### 2.3 消融设计（对应报告"不同超参数比较"一节）

至少做三组，每组只改一个变量：

1. **损失函数**：BCE / Dice / 0.5BCE+0.5Dice（预期混合最好，解释为什么：Dice 对前景少敏感但梯度不稳）；
2. **输入分辨率**：192 / 256 / 384（预期 384 提升明显但耗时翻倍，用来讨论"精度-成本权衡"）；
3. **注意力位置**（仅 Attention U-Net）：只在 skip 上 / 只在 bottleneck / 全加。

### 2.4 评价指标（必须自己写对）

| 指标 | 定义要点 | 为什么必须报 |
| --- | --- | --- |
| **Dice** | 2\|P∩G\| / (\|P\|+\|G\|) | 主指标，医学分割通用语言 |
| **IoU (Jaccard)** | \|P∩G\| / \|P∪G\| | 与 Dice 单调但更严格，论文常并列 |
| **HD95** | 95% 分位 Hausdorff 距离（mm 或像素） | **边界质量**唯一可信指标；Dice 高的模型 HD95 可能很差，这个反差是报告亮点 |
| Sensitivity / Specificity | 逐像素 | 医学场景关心"漏诊 vs 误诊"的取舍 |
| 像素准确率 | — | **只用来做反面教材**：全预测背景也能 85%+，证明它无意义 |

> HD95 需要 `medpy` 或 `surface-distance`，注意实现时对空掩膜的处理（ISIC 里有少量空掩膜样本，要单独统计，别让除零把结果污染）。

## 3. 作业 2：SAM 提示分割

### 3.1 SAM 原理（学习的重点在这三块）

| 组件 | 结构 | 你要能吃透的问题 |
| --- | --- | --- |
| **Image encoder** | ViT-B/L/H，输入固定 1024×1024，patch 16 → 64×64=4096 tokens；大部分层用窗口注意力（window 14），仅少数层做全局注意力 | 为什么输入必须 1024？窗口注意力解决了什么显存问题？ |
| **Prompt encoder** | 点 → 位置编码 + 类型嵌入；框 → 两个角点的嵌入；掩膜 → 卷积下采样 | 框为什么编码成"左上+右下"两个角点，而不是中心+宽高？ |
| **Mask decoder** | 2 层，含 **token→image 与 image→token 的双向交叉注意力**，输出 3 个掩膜（整物体/部分/子部分）+ IoU 预测分数 | 三个掩膜是干什么的？IoU 分数怎么用来选？ |

**论文清单（按这个顺序读，别乱序）**：
1. U-Net（1505.04597）—— 先把编码解码与跳跃连接吃透；
2. Attention U-Net（1804.03999）—— 注意力门控怎么算；
3. V-Net / Dice loss（1606.04797）—— 为什么分割不能只用交叉熵；
4. **SAM（2304.02643）**—— 重点读 §3 任务定义、§4 模型三件套；
5. **MedSAM（Nature Communications 2024）**—— 医学域怎么微调、为什么只用 box 提示；
6. **SAMed（2304.13785）**—— LoRA 怎么注入 ViT，这是你"低秩适配"那部分的依据。

### 3.2 三个递进实验（这就是"复杂任务"的骨架）

| 实验 | 设置 | 回答什么问题 | 预期 |
| --- | --- | --- | --- |
| **E1 零样本** | 原版 SAM ViT-B，不做任何训练，用 GT 框当提示 | 通用大模型在皮肤镜上到底行不行？ | Dice 中等（域偏移明显），边界尚可但小病灶差 |
| **E2 冻结编码器 + 微调 decoder**（MedSAM 式） | image encoder 冻结，只训 prompt encoder + mask decoder | 只调 4% 参数能挽回多少域差距？ | Dice 大幅提升，逼近甚至超过作业 1 最佳 U-Net |
| **E3 LoRA 微调编码器**（SAMed 式） | 在 ViT 的 q/v 投影注入 LoRA（r=8），连同 decoder 一起训 | 给 Transformer 主干"松绑"值不值？ | 比 E2 再涨 1–3 点，但训练成本翻数倍 |

**E1→E2→E3 就是一条完整的消融链**，直接回答"Transformer 模块的贡献在哪里、要付多少代价"，比任何空洞的"我们用了大模型"都有说服力。

### 3.3 一个能让本机跑得动的关键优化（务必写进报告）

**冻结 image encoder 时，图像嵌入与提示无关，可以预计算一次并缓存**：

- 2,594 张图 × 256×64×64（fp16）≈ **约 5 GB**，磁盘完全放得下；
- 效果：E2 训练时每个 epoch 只需跑 mask decoder，**从"每 epoch 十几分钟"降到"几十秒"**；
- 这是 SAM 微调的标准工程手法，写进报告能体现你懂"训练成本来自哪里"。

预计算本身：2,594 张 × 约 0.4–0.6 s/图 ≈ **20 分钟**（估算，一次性）。E3 因为要动 encoder，无法缓存，必须在线前向：bs=2 时约 1.5 s/步，1,297 步/epoch ≈ **30 分钟/epoch**，10 epoch 约 **5 小时**——必须分段跑，且要接受 Air 的降频。

### 3.4 提示设计：必须讨论的"作弊"边界

| 提示类型 | 说明 | 用途 |
| --- | --- | --- |
| **GT 框** | 用金标准掩膜的外接矩形 | 与 MedSAM 等文献对齐（他们也这么做），作为主结果 |
| 扰动框 | GT 框外扩/内缩 10%、20% | **鲁棒性实验**：量化"提示不准时掉多少"——这是报告最有价值的一张图 |
| 中心点 / 多点 | 单点、3 点、5 点 | 讨论点提示与框提示的信息量差异 |
| 自动框 | 用作业 1 最佳 U-Net 的预测框当提示 | **闭环实验**：证明"小模型提框 + 大模型精修"的级联可行性 |

第四行是能出彩的地方：它把作业 1 和作业 2 真正缝在一起，形成"自动分割 → 提示生成 → 交互式精修"的完整系统，而不是两个独立作业。

### 3.5 与作业 1 的正面对比（报告的核心表格）

| 维度 | U-Net（作业 1） | SAM 微调（作业 2） |
| --- | --- | --- |
| Dice / HD95 | 低 / 差 | 高 / 好 |
| 参数量 | ~31 M | 91 M（LoRA 可训参数仅 ~0.5 M） |
| 推理时延 | 快（单图 ~10 ms 级） | 慢（单图 ~0.5 s，含编码） |
| **是否需要人工提示** | **不需要** | **需要（框/点）** |
| 换数据集的迁移成本 | 必须重训 | 零样本可用，微调更快收敛 |

**结论句（报告里要高亮）**：小模型赢在"部署成本与自动化"，大模型赢在"跨域泛化与少样本适配"，两者不是替代关系而是分工关系——**临床流程里应该是 U-Net 出粗框、SAM 做精修**。

## 4. 学习路线（四个阶段，带验收标准）

你没做过这两个方向，所以路线要按"能自己讲出来"而不是"能跑通"来设计。每阶段末尾的**自测问题答不上来，就不要进下一阶段**。

### S0 概念补齐（1–2 天）

- 学：语义分割与分类的区别、one-hot 掩膜、上采样/转置卷积、感受野、Dice/IoU/HD95 的定义与关系。
- 产出：一页笔记，手写 Dice 与 IoU 的换算公式（Dice = 2IoU/(1+IoU)）。
- **验收**：能解释"为什么像素准确率 99% 的分割模型可能完全没用"。

### S1 手写 U-Net（3–4 天）

- 学：U-Net 原论文 + 自己**从零实现一遍**（不用现成库的 UNet 类）。
- 要点：4 次下采样、跳跃连接是 concat 不是 add、输出 1 通道不加 softmax。
- 产出：能训到 Dice ≥ 0.75 的基线（ISIC 上这个数合理）。
- **验收**：能画出自己的张量形状变化表（256→128→64→32→16，通道 64→1024），并解释 skip 连接解决的是什么问题。

### S2 改进模型与实验方法（4–5 天）

- 学：ResUNet 的残差块、Attention U-Net 的注意力门控（重点看 gating signal 从哪来）。
- 学：消融实验的写法、随机种子与方差、早停与学习率调度。
- **验收**：能解释"为什么 Attention U-Net 的注意力图很好看但 Dice 只涨 0.5 个点"——这题答得好，报告的分析章节就稳了。

### S3 SAM 吃透（4–5 天）

- 学：SAM 论文三件套 + 官方 demo 跑通（`segment_anything` 包，ViT-B 权重约 375 MB）。
- 重点：把 mask decoder 的双向交叉注意力数据流画出来（prompt tokens 与 image tokens 怎么互相 attend）。
- **验收**：能回答"为什么 SAM 不能直接替代 U-Net 做全自动分割"（答案：它需要提示，且 1024 输入成本高）。

### S4 微调与系统集成（5–7 天）

- 学：MedSAM 的微调配方（只训 decoder、box 提示、Dice+BCE）、LoRA 注入方式。
- 做：E1/E2/E3 三实验 + 扰动框鲁棒性 + 级联闭环。
- **验收**：能画出完整系统图并说清"每个模块失败了会怎样"。

## 5. 环境适配（M5 的四个硬约束）

| 约束 | 影响 | 处置 |
| --- | --- | --- |
| 无 CUDA，只有 MPS | 部分算子缺失 | `PYTORCH_ENABLE_MPS_FALLBACK=1`；`device` 三级回退 cuda→mps→cpu |
| fp32 算力弱（实测 3.33 TFLOPS，fp16 为 13.6） | 不开 autocast 慢 4 倍 | **强制 `torch.autocast("mps", dtype=torch.float16)`** |
| 24 GB 统一内存 | SAM 1024² + ViT-B 训练吃紧 | 冻结 encoder + 缓存嵌入；E3 用 bs=2 + 梯度累积 |
| **Air 无风扇** | 连续 1 小时以上降频 | 每 20–30 分钟存 checkpoint 后重启；长训练放夜里分段 |
| HuggingFace 不可达 | 权重下载卡死 | `HF_ENDPOINT=https://hf-mirror.com`；SAM 权重可从 Meta 官方或 ModelScope 取；缓存放项目内 |

**权重清单**：SAM ViT-B checkpoint（~375 MB）、ISIC 2018 数据（~1.5 GB）、预计算嵌入缓存（~5 GB）。磁盘 797 GB 充裕。
