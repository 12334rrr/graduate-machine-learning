## 二、本轮新发现并修复的问题（计划外）

### N1. `documents/导出报告.sh` 的 Chrome 缺 `--no-sandbox`（P4 同类Bug，计划外发现）

- **现象**：重跑打包脚本时 Chrome 无头打印 PDF 直接 `Trace/BPT trap: 5` 崩溃，`set -e` 捕不到 shell trap，PDF 静默不生成。
- **修复**：Chrome 调用加 `--no-sandbox`，并增加 PDF 生成后非空校验（`[ -s ... ] || exit 1`），失败即报错不再静默。
- **附带**：清理了崩溃残留的 `/tmp/report_css_XXXX.css`（导致 mktemp "File exists" 连锁失败）。

### N2. 沙箱 `HTTP_PROXY` 泄漏导致门禁测试误红（本轮最大坑）

- **现象**：`test_api_endpoints` skip（`HTTP Error 502`）、Chrome 冒烟 `ERR_CONNECTION_REFUSED`。
- **根因**：沙箱注入了 `HTTP_PROXY=http://127.0.0.1:55515` 等变量——Python `urllib` 与 Chrome 都把发往 `127.0.0.1:8800` 的请求走了代理。
- **修复**：
  - `tests/test_hub.py`：localhost 冒烟改用 `ProxyHandler({})` 无代理 opener；
  - `tests/run_all.sh`：Chrome 加 `--no-proxy-server`。
- **验证**：两项从 skip/失败变为 ok/通过。

### N3. 3 个 E3 僵亡进程占用 `.conda`（P5 前置阻塞）

- **现象**：删除 `.conda` 前 `lsof` 发现 PID 60848/62076/62077 仍映射其中的库。
- **定性**：三个进程均为 10-18 16:48 卡死的 E3 训练残留（日志 39 小时无写入；正式 E3 产物 18:55 已由重跑完成并落盘），各带 1 个 `torch_shm` 守护子进程。
- **处置**：确认无子进程、无活跃写入、产物已完成后终止，`.conda` 引用清零后删除（回收 615 MB）。
