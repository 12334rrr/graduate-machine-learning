   - **展示层**：hw1 仪表盘(8801)、hw2 仪表盘(8802)、数据集平台(8800)；
   附 ASCII 或 Mermaid 架构图讲清三者关系与端口分配。
3. 平台内"架构说明"页（`#/about`）：分层架构图（可用内嵌 SVG 手绘：浏览器 ⇄ HTTP ⇄ server.py ⇄ data/*.json / DeepSeek API / 磁盘项目文件），模块划分表，前后端协作时序说明（轮询、SSE 流式、链接检测三条链路）。

### 3.2 前端视觉升级

**参考对象**：Papers with Code 的信息密度、Hugging Face 的卡片与标签体系、Kaggle 的干净表格。**浅色主题**（与前两个暗色监控台刻意区分：监控 = 暗色，展示 = 浅色）。

**设计规范（硬性）**：

- 配色：主色 `#1a73e8`（或同气质蓝），背景 `#f8f9fa`，卡片纯白 `#ffffff`，边框 `#e0e3e8`，正文 `#1f2329`，次要文字 `#5f6470`，强调色（许可证/榜单）`#188038`；禁止花哨渐变。
- 字体：中文 PingFang SC / 思源黑体回退，英文/数字/代码 SF Mono / Menlo；标题字重 600。
- 卡片：圆角 8px、1px 边框、hover 时轻微上浮（translateY -2px + 阴影），不使用重投影。
- 布局：顶部导航栏（平台名 + 视图链接 + 环境状态点）；首页 = hero 区（项目一句话 + 三个关键数字：数据集数 / 术语数 / 榜单来源数）+ 精选数据集卡片 + 平台能力说明；列表页 = 分类筛选 chips + 搜索框（前端过滤）+ 卡片网格；详情页 = 面包屑 + 左侧主栏（描述/统计表/下载列表/榜单）+ 右侧边栏（许可证、格式、大小、关联术语 chips）。
- 响应式：≥1100px 三列卡片、768–1100px 两列、<768px 单列且侧边栏堆叠到主栏下方；导航在窄屏折叠。
- **状态完备**：每个异步区块必须有 loading 骨架（灰色脉冲条）、空数据态（插画位 emoji + 引导文案）、错误态（红色提示条 + 重试按钮）；`/api/*` 失败时页面不白屏。

### 3.3 数据集下载中心

- 详情页下载区块：每个文件一行——文件名、格式、大小、来源徽标（"官方直链"/"镜像"）、【复制链接】【打开下载】【检测】三按钮。
- 【检测】调 `GET /api/check_link?url=`：后端 HEAD 请求（10s 超时），前端显示 🟢 可达（含 Content-Length 换算的体积）/ 🔴 不可达 + 明确原因文案（超时/HTTP 状态码/DNS）+ 引导语（"可尝试下方镜像源"）。
- 镜像源单独成组展示，注明适用场景（如"hf-mirror：官方 S3 不可达时"）。
- 许可证用绿色徽标展示，附一句话解释（glossary 里有 CC BY-NC 4.0 / Apache 2.0 词条，点击可跳术语表）。

### 3.4 术语与知识说明

- **悬浮释义**：详情页/首页正文中出现的术语用 `<span class="term" data-term="Dice">` 包裹（点状下划线样式），hover 弹出 tooltip 卡片（术语名、英文全称、一句话定义），点击跳术语表对应锚点。
- **术语表页**（`#/glossary`）：按分类分组展示（评价指标/模型架构/SAM 组件/任务范式/工程优化/许可证…），顶部字母/分类筛选 + 搜索；每条 = 术语名、英文、分类 chip、定义、公式（若有，等宽字体框）。
- 前端在启动时拉一次 `/api/glossary` 缓存到内存，tooltip 数据从中取。

### 3.5 官方榜单

- 数据已在 `datasets.json` 的 `leaderboards` 字段（ISIC 官方榜单、Papers with Code、MedSAM 论文、SA-1B 论文等），前端详情页渲染为"官方榜单与论文对标"卡片：榜单名（外链新窗口）、排名依据指标、备注。
- 首页可加一个"榜单速览"横条：ISIC 2018 官方指标 = 阈值化 Jaccard（IoU）、ISIC 2019 = Balanced Accuracy。
- 不要编造榜单数字；数据来自 datasets.json，需要新增条目时只加官方/论文可考来源。

### 3.6 DeepSeek 智能问答助手

**安全约束（红线）**：API key 只允许出现在 `dataset_hub/.env` 与用户 shell 环境变量中；**前端 JS、HTML、git 提交中一律不得出现密钥明文**；`.gitignore` 必须包含 `.env`。

**后端**（`server.py`）：

- 启动时读取 `os.environ["DEEPSEEK_API_KEY"]`，不存在则解析同目录 `.env`（KEY=VALUE，# 注释，`os.environ.setdefault` 不覆盖已有环境变量）。
- `POST /api/chat`，请求体 `{"messages": [{role, content}, ...]}`（前端带完整多轮历史，后端截断保留最近 20 条）。
- 后端向 `https://api.deepseek.com/chat/completions` 发 `stream=true` 请求（`http.client.HTTPSConnection`，model 用环境变量 `DEEPSEEK_MODEL`，默认 `deepseek-chat`，temperature 0.3），把 SSE 行**原样透传**给前端（`Content-Type: text/event-stream`，边读边 flush）。
- 系统提示词（写在后端常量里）：说明助手身份 = 本平台内置研究助手，能解释项目结构（hw1 三模型、hw2 E1/E2/E3、级联叙事）、数据集（内容/下载/许可证）、指标与术语；要求简体中文、专业易懂、不知道的数字不编造。
- key 缺失或 API 报错时，SSE 里返回 `{"error": "明确的中文原因"}`，前端友好展示，不崩。

**前端**：

- 右下角悬浮聊天按钮（圆形，主色），点击展开聊天面板（约 380×520px，窄屏全宽抽屉）。
- 多轮对话：维护 messages 数组随请求发送；用户消息右气泡、助手左气泡；助手回复用 `fetch + ReadableStream` 逐行解析 SSE `data:` 行，**增量渲染**（打字机效果），markdown 粗体/代码内联即可。
- 预设三个快捷问题 chips："ISIC 2018 数据集怎么下载？"、"Dice 和 IoU 有什么区别？"、"E1/E2/E3 三阶段分别在做什么？"。
- 对话中术语可点击跳术语表（可选加分项）。

**配置**：

```bash
# dataset_hub/.env（gitignore，本地）
DEEPSEEK_API_KEY=sk-已脱敏（真实值只存于 dataset_hub/.env，勿写入文档）
DEEPSEEK_MODEL=deepseek-chat
```

`.env.example` 只放键名不放值。README 写清两种配置方式（.env 文件 / export 环境变量）与优先级。

## 4. 后端 API 规格（`server.py`，端口 8800）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 返回 `static/index.html` |
| GET | `/api/overview` | `{datasets: 数量, terms: 数量, leaderboard_sources: 数量, chat_enabled: bool, server_time}` |
| GET | `/api/datasets` | 返回 `data/datasets.json` 全文 |
| GET | `/api/glossary` | 返回 `data/glossary.json` 全文 |
| GET | `/api/check_link?url=` | HEAD 探测，10s 超时；返回 `{ok, status, size_bytes, message}`；超时/DNS/HTTP 错误分类给中文 message |
| POST | `/api/chat` | DeepSeek SSE 透传代理（见 §3.6） |

工程要求：仅标准库；`ThreadingHTTPServer`；绑定 `127.0.0.1`；所有读文件操作防目录穿越；`Cache-Control: no-store`；错误统一返回 `{"error": "中文说明"}` + 合适状态码。
