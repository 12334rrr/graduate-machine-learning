## 4. 作业 1 执行规格

### 4.1 数据

| 项    | 规格                                                             |
| ---- | -------------------------------------------------------------- |
| 数据集  | ISIC 2018 Task 1，训练 2,594 + 验证 100 + 测试 1,000，掩膜齐全             |
| 存放   | `hw1_unet/data/raw/`，**禁止落在 `~/.cache`**                       |
| 划 分  | 优先官方 split；最终对比额外跑 5 折交叉验证（只用于最佳的 2 组超参）                       |
| 预处理  | resize 到 256×256，ImageNet 均值方差归一化                              |
| 增强   | 随机水平/垂直翻转、旋转 ±30°、缩放 0.8–1.2、色彩抖动；**验证集只 resize + 归一化**        |
| 首日必做 | 统计**前景像素占比分布**、检查**是否存在空掩膜/多连通域**，结果写入 `reports/data_stats.md` |

### 4.2 三个模型（必须手写，见 §7 禁止事项）

| 模型              | 论文                       | 关键实现点                                                |
| --------------- | ------------------------ | ---------------------------------------------------- |
| U-Net           | Ronneberger, MICCAI 2015 | 4 次下采样，跳跃连接是 **concat 不是 add**，输出 **1 通道不加 softmax** |
| ResUNet         | Zhang, GRSL 2018         | 编码/解码块改为残差块（conv-bn-relu-conv-bn + 跳跃相加）             |
| Attention U-Net | Oktay, MIDL 2018         | 跳跃连接上加**注意力门控**，gating signal 来自解码器上一层               |

### 4.3 训练配置（先按这个跑，别一上来就调）

| 参数           | 值                                                                     |
| ------------ | --------------------------------------------------------------------- |
| 输入尺寸 / batch | 256×256 / **8**                                                       |
| 优化器 / 学习率    | AdamW / **1e-3** / cosine 退火（从零训 U-Net 不要用 1e-4）                      |
| 损失           | **0.5×BCE + 0.5×Dice**                                                |
| epoch / 早停   | 30 / patience=8                                                       |
| 精度           | **必须 `torch.autocast(device_type="mps", dtype=torch.float16)`**       |
| 设备           | 自动探测 `cuda → mps → cpu`，**禁止硬编码 mps**                                 |
| 随机种子         | 固定 42；**关键对比跑 3 个种子，报告均值 ± 标准差**                                      |
| 存盘           | 每 epoch 存一次 checkpoint 到 `outputs/checkpoints/`，每 5 epoch 存一次验证集预测样例图 |

### 4.4 消融实验（报告"不同超参数设置比较"一节的内容）

1. **损失函数**：BCE / Dice / 0.5BCE+0.5Dice（三选一前先各跑一次）；
2. **输入分辨率**：192 / 256 / 384（讨论精度-成本权衡）；
3. **注意力位置**（仅 Attention U-Net）：仅 skip / 仅 bottleneck / 全部。

### 4.5 评价指标（自己实现，别只看库）

| 指标                        | 定义                  | 备注                                                    |
| ------------------------- | ------------------- | ----------------------------------------------------- |
| Dice                      | 2|P∩G| / (|P|+|G|)  | 主指标                                                   |
| IoU                       | |P∩G| / |P∪G|       | 与 Dice 单调但更严格                                         |
| **HD95**                  | 95% 分位 Hausdorff 距离 | 用 `medpy` 或 `surface-distance`；**空掩膜必须单独统计，禁止除零污染结果** |
| Sensitivity / Specificity | 逐像素                 | 讨论漏诊 vs 误诊取舍                                          |
| 像素准确率                     | —                   | **只作反面教材**：证明背景占比 85% 时全预测背景也有 85% 准确率，说明它无意义         |

**预期基线**：U-Net Dice ≥ 0.75（ISIC 上合理）。达不到先查损失、归一化、掩膜是否反色。

## 5. 作业 2 执行规格

### 5.1 SAM 三阶段实验

| 实验             | 设置                                                               | 目的                         |
| -------------- | ---------------------------------------------------------------- | -------------------------- |
| **E1 零样本**     | 原版 SAM ViT-B（`sam_vit_b_01ec64.pth`，91M），**不训练**，用 GT 外矩形框作提示    | 量化通用大模型在皮肤镜上的域差距           |
| **E2 冻结编码器**   | image encoder **冻结**，仅训练 prompt encoder + mask decoder（MedSAM 式） | 只调约 4% 参数能挽回多少             |
| **E3 LoRA 微调** | 在 ViT 的 **q/v 投影**注入 LoRA（r=8），连同 decoder 训练（SAMed 式）            | 给 Transformer 主干"松绑"的增量与代价 |

### 5.2 关键工程优化（务必实现，写进报告）

**冻结 image encoder 时，图像嵌入与提示无关 → 预计算一次并缓存**：

- 缓存 `hw2_sam/data/embeddings/`，2,594 张 × 256×64×64 fp16 ≈ **5 GB**；
- E2 训练每 epoch 从"十几分钟"降到"几十秒"；
- E1 评测与 E2 训练共用同一份缓存。

**E3 无法缓存**（要动 encoder），需在线前向：bs=2 + 梯度累积，约 30 min/epoch，10 epoch ≈ 5 小时，**必须分段跑并 checkpoint**。

### 5.3 提示设计（报告里最有价值的一章）

| 提示              | 说明                     | 用途                                  |
| --------------- | ---------------------- | ----------------------------------- |
| GT 框            | 金标准掩膜的外接矩形             | 主结果（与 MedSAM 等文献对齐）                 |
| **扰动框**         | GT 框外扩/内缩 **10%、20%**  | 鲁棒性曲线：提示不准时掉多少，这是最出彩的一张图            |
| 中心点 / 3 点 / 5 点 | 点提示                    | 讨论点提示与框提示的信息量差异                     |
| **自动框（级联）**     | 用作业 1 最佳 U-Net 的预测框作提示 | **把两个作业缝成一条系统**：自动分割 → 提示生成 → 交互式精修 |

**关于"GT 框算不算作弊"**：在报告里**主动写清**这是交互式分割的标准设定（MedSAM 同样如此），并用扰动框 + 自动框两个实验证明结论在提示不完美时依然成立。把质疑变成章节，而不是回避。

### 5.4 与作业 1 的正面对比（报告核心表格）

| 维度          | U-Net（作业 1） | SAM（作业 2）             |
| ----------- | ----------- | --------------------- |
| Dice / HD95 | 低 / 差       | 高 / 好                 |
| 可训练参数       | ~31 M       | 91 M（LoRA 可训仅 ~0.5 M） |
| 单图推理时延      | ~10 ms 级    | ~0.5 s（含 1024 编码）     |
| 是否需人工提示     | 否           | 是                     |
| 换数据集迁移      | 需重训         | 零样本可用                 |

**结论句（报告高亮）**：小模型赢在自动化与部署成本，大模型赢在跨域泛化与少样本适配，**临床流程里应是 U-Net 提框、SAM 精修**。

## 6. 工程规范（硬性）

1. **设备与精度**：`device` 三级回退 `cuda → mps → cpu`；只在这台机器上跑时开 `autocast(mps, fp16)`；缺失算子用 `PYTORCH_ENABLE_MPS_FALLBACK=1` 兜底。
2. **可复现**：所有随机种子固定；`requirements.txt` 导出（`pip freeze > requirements.txt`）；README 写清激活命令与 `HF_ENDPOINT=https://hf-mirror.com`。
3. **路径**：全部用相对路径或项目根常量，**禁止硬编码 `/Users/wangchunbo/...` 绝对路径**。
4. **日志**：每个实验一个 `outputs/logs/<模型>_<日期>.csv`，记录 epoch / lr / loss / dice / iou / hd95 / 耗时。
5. **备份**：代码进 git；checkpoints 与数据定期打包备份（本机是单点，盘坏了 6 周工作量归零）。
6. **散热**：Air 无风扇，**单次连续训练不超过 20–30 分钟**，长训练必须分段 + checkpoint 续跑。
7. **下载**：SAM 权重优先 `https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth`（375 MB），若不可达改从 ModelScope 或 `hf-mirror` 取 `facebook/sam-vit-base`。

## 7. 禁止事项（违反即返工）

| 禁止                                                  | 原因                                           |
| --------------------------------------------------- | -------------------------------------------- |
| **用 MONAI / segmentation_models_pytorch 的现成 U-Net** | 作业要考察模型实现理解，抄库就失去意义；**必须手写**，这是学习路线的 S1 阶段要求 |
| 把数据或权重下到 `~/.cache`                                 | 换机/重装即失效，且老师无法复现                             |
| 一次性跑完所有 epoch 不存盘                                   | Air 降频 + MPS 偶发崩溃，会全盘皆输                      |
| **编造或美化指标数字**                                       | 指标不好就如实写并分析原因，这本身就是报告要求的"实验证实了哪些缺点"          |
| 只跑一个种子就下"模型 A 优于 B"的结论                              | 差异小于 0.5 点时要用多种子均值 ± 标准差 + 配对检验，或老实说"不显著"    |
| 作业 1 与作业 2 各写一份互不相干的报告                              | 必须共用一张系统图（级联实验），否则"复杂任务"叙事不成立                |
