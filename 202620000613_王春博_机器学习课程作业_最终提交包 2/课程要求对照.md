# 课程原始要求对照

作业一选择医学图像分割编程，手写三种卷积网络。作业二使用SAM，ViT-B和Two-Way两处包含Transformer。

| 原始报告要求 | 本报告位置 |
| --- | --- |
| 名称与摘要 | 封面、第一部分 |
| 背景 现有方法 自己的思路 | 第二部分 |
| 模型原理与结构图 | 第三部分 图1至7 |
| 数据分析 划分 预处理 指标 超参数 | 第四部分 |
| 多模型总体比较 | 5.1及5.3 |
| 不同超参数设置比较 | 5.2损失 尺寸 门控；5.3提示工程 |
| 测试真实标签与预测 | 5.4 图14和15 |
| 总结与高亮个人观点 | 第六部分 |
| 源码提交 | repository |

课程未规定字数、三种子、五折或Dice达标线。E2/E3及384输入的问题已通过独立重训与全测试复评闭环；其余正式实验核对后保留，证据见验证记录/完整复验。
