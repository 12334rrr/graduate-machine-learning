## 3 数据与权重

从仓库根目录执行，保持三个项目的同级关系：

```bash
cd hw1_unet
python src/download_isic.py
python src/prepare_data.py --size 384
cd ../hw2_sam
python src/download_sam.py
cd ..
```

数据下载脚本使用 ISIC 官方资源，得到 train 2594、val 100、test 1000。预处理后 `hw1_unet/data/processed` 中应有每个 split 的 `*_images.npy`、`*_masks.npy` 和 `*_ids.txt` 等文件。384母版在训练/评测时再按相应输入尺寸读取。官方链接可达性依赖执行时网络，失败时从 ISIC 官方页面手动取得同名文件并放入 `hw1_unet/data/raw`，不可随意换成另一划分。

SAM ViT-B 权重应位于 `hw2_sam/data/raw/sam_vit_b_01ec64.pth`。提交包包含E2、E3与384输入的推理用best权重，逐张量验证与原训练权重一致，见推理权重校验.json；不含优化器与续跑状态。原始数据、官方SAM基础权重和约7.75GB原版嵌入需另行准备。结果展示不依赖这些大输入。

## 4 先做小规模验证

在具备对应环境及数据后，使用压缩包的快速入口：

```bash
python quick_reproduce.py smoke unet
python quick_reproduce.py smoke e1
```

U-Net入口只训练16张、1轮、192输入、batch2，并在验证集评估；E1入口只评估test前3张、GT框提示。源码会复制到 `reproduction_runs/时间戳_任务/`，输入数据使用链接读取，新日志和权重都写入该隔离目录，避免覆盖正式记录。已有完整数据在其他项目根目录时，使用 `--data-root "/完整项目根目录"`。该参数指向同时包含 `hw1_unet` 和 `hw2_sam` 的根目录。

本次在原机器已有数据与权重上，两条小规模入口均实际执行通过；它们只证明代码链路可运行，不能代替1000张测试集全量复评，也不能据此声称原始指标已完全复现。训练耗时随设备、缓存和温度变化，不承诺固定用时。

## 5 重跑 U-Net 系列和级联上游

建议先在单独克隆/解压副本中实验，避免覆盖历史输出；正式运行不要保留 `--subset`。以下命令来自实际 argparse 与编排配置：

```bash
cd hw1_unet
python src/run_all.py --only main
python src/run_all.py --only ablation
python src/run_cv.py
python src/evaluate.py --tag unet_s42 --split test --size 256 --save-boxes
cd ..
```

主实验为3模型×3种子，12轮上限、patience6；消融有6个附加运行，默认组复用主实验。单次分段预算25分钟在整轮结束后检查。分段训练需要保留 `*_last.pth`。单独调用 `train.py` 时应显式传 `--epochs 12 --patience 6`，其默认值为30/8。分辨率消融评估要匹配 `--size 192` 或 `--size 384`。级联输入文件为 `hw1_unet/outputs/predictions/unet_s42_test_boxes.json`，不得替换为其他上游却沿用同一结果名称。

## 6 重跑 SAM 阶段和提示矩阵

E1/E2使用固定原版图像编码器的嵌入缓存；E3在线更新ViT低秩增量，不能读取原版缓存替代在线编码。预计算三个划分后，先验证无训练的E1：

```bash
cd hw2_sam
python src/precompute_embeddings.py --split train
python src/precompute_embeddings.py --split val
python src/precompute_embeddings.py --split test
python src/evaluate_sam.py --stage e1 --prompt gt --split test
python src/evaluate_sam.py --stage e1 --prompt auto \
  --split test --unet-tag unet_s42
cd ..
```

下列为修复后训练入口。请在独立副本使用新tag，从官方权重重新训练E2，并为新实验保存代码与权重哈希；不要将旧监督训练的checkpoint作为修复后训练起点。

```bash
cd hw2_sam
python src/e2_finetune.py --tag e2_box --epochs 20 --batch 8 --max-minutes 100000 --num-workers 0
python src/e3_lora.py --tag e3_lora --epochs 6 --batch 1 --accum 8 \
  --train-limit 600 --val-limit 100 --lora-r 8 --lora-alpha 16 --max-minutes 100000
```

本次正式实验连续运行，避免分段续跑改变随机轨迹；E2实际20轮、best第9轮，E3实际6轮、best第2轮。编排按实际epoch和目标轮数判断完成，未完成将报错。提交包推理best不用于--resume；重训请删除独立副本中的best或使用新tag。

权重准备完成后，对每个阶段运行十种提示；E1 tag填e1，E2填e2_box，E3填e3_lora：

```bash
for prompt in gt pert-20 pert-10 pert10 pert20 \
  point1 point3 point5 auto auto10; do
  python src/evaluate_sam.py --stage e3 --tag e3_lora \
    --prompt "$prompt" --split test --unet-tag unet_s42
done
cd ..
```

原编排只自动评E1/E2级联，E3的auto/auto10需要上述显式命令。历史评测文件名按stage、prompt、split命名，未包含完整训练tag；因此重评应在独立副本执行或先修改新版输出隔离策略。本版已取消E2缓存特征翻转、完整恢复E3 prompt encoder及LoRA缩放参数、在保存last前更新最佳状态，并修复轮数完成判定。历史E3日志第3轮峰值对应权重缺失，无法追溯恢复，应独立重新训练并选择权重。评测可加 `--output-dir ../复验结果` 隔离输出。

## 7 验收与结果定位

验收顺序为：结构检查通过 → 门户可打开并显示两项目的画廊图片 → 正式汇总重算一致 → 数据和官方权重就位 → 小规模链路通过 → 修复后独立训练与全量评测 → 核对新配置和哈希。结果展示与新实验分开验收。

正式主表应能重算 U-Net 0.5939±0.0218、ResUNet 0.6077±0.0194、Attention U-Net 0.6080±0.0148；E2 GT框0.9181、auto0.6918，E3 GT框0.8970。其余提示以正式JSON为准。它们用于检查读取和汇总是否正确，不保证不同设备的新训练得到逐位相同成绩。

`outputs/logs` 保存JSON与CSV，`outputs/figures` 保存实际画廊图片，`outputs/predictions` 保存自动框。精简报告的正文图直接由原始JSON/CSV生成，37张门户原图收入压缩包根目录的离线HTML电子图录；原图SHA256及其用途见交付根目录 `图片来源索引.json`。
