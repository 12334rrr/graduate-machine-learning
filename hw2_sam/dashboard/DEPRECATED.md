# ⚠️ 本目录已废弃（2026-10-18）

这个暗色监控台（端口 **8802**）的**全部功能已并入一站式门户 `dataset_hub`**，不再维护、也不再需要启动。

## 功能迁移对照

| 原 8802 功能 | 现在在哪里（:8800） |
| --- | --- |
| E1/E2/E3 三阶段流水线状态 | [`#/hw2`](http://127.0.0.1:8800/#/hw2) 三张阶段卡（含最佳 Dice/IoU/HD95） |
| 图像嵌入预计算进度 | `#/hw2` 嵌入缓存进度条（train/val/test + 体积） |
| 评测结果一览 | `#/hw2` 评测档案（点击查看完整指标 + 原始 JSON） |
| 评测报告弹窗 | `#/hw2` 同上（含原始 JSON 折叠查看） |
| 训练运行 / 曲线 | `#/hw2` 训练曲线（E2/E3 运行后自动出现） |
| 核心代码浏览（src/） | `#/hw2` 源码卡片 |
| 模型权重下载 | `#/hw2` Checkpoints（含 SAM 原版 ViT-B 权重） |
| 图表产物浏览 | `#/hw2` 图表画廊 |
| 报告文档浏览 | `#/hw2` 报告文档卡片 |
| 暗色主题 | 全站支持：导航栏 🌙/☀️ 一键切换 |

## 门户新增（原 8802 没有的）

- **提示类型对比柱状图**：GT 框 / 扰动框 ±10%/±20% / 点提示 1·3·5 各阶段 Dice 对比
- **扰动框鲁棒性曲线**：提示不准时 Dice 掉多少（报告里最有价值的一张图）
- **级联系统叙事卡**：把作业 1 与作业 2 缝成一条系统
