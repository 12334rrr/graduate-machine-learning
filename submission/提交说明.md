## 环境

- 机器：MacBook Air（Apple M5，24 GB 统一内存，MPS，无 CUDA）
- Python 3.11 / torch 2.14.1 / torchvision 0.29.1
- 两个 conda 环境：`hw1-unet-medseg`、`hw2-sam-transformer`（依赖见各自的 `requirements.txt`）

## 复现（简要）

```bash
# 作业 1
conda activate hw1-unet-medseg
cd hw1_unet
python src/download_isic.py          # 数据（约 14 GB）
python src/prepare_data.py
python src/run_all.py                # 9 组主对比 + 6 组消融
python src/collect_results.py
python src/run_cv.py                 # 五折交叉验证（最佳 2 组超参）

# 作业 2
conda activate hw2-sam-transformer
cd hw2_sam
python src/download_sam.py           # SAM ViT-B 权重（375 MB）
python src/precompute_embeddings.py --split train
python src/run_all.py                # E1 → E2 → E3 → 级联 → 出图
python src/plot_cases.py             # 定性案例图
```

## 说明（口径与限制）

- 训练预算：为保证无风扇机器可完成，主实验统一为 **12 epoch + patience 6**（报告中已披露）。
- 作业 2 的 E3 使用 **600 张子集 × 6 epoch**（全量在线训练约 17 小时），所有对比均标注该口径。
- 数据、SAM 权重、嵌入缓存（7.2 GB）与模型 checkpoints 体积过大，未放入压缩包；
  按 README 的下载/预计算脚本可完整重建。
- 指标均由 `outputs/logs/eval_*.json` 汇总，报告数字与日志一致；差异小于种子标准差时只表述为“不显著”。
